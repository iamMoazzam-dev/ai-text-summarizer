# AI Text Summarizer

A beginner-friendly Generative AI application that summarizes user-provided text using a pretrained DistilBART model and Gradio.

## Features

- Enter text through a web interface
- Generate an AI-powered summary
- Input validation for empty text
- Simple Gradio user interface
- Uses a pretrained Hugging Face Transformers model

## Technologies

- Python
- PyTorch
- Hugging Face Transformers
- Gradio

## Model

`sshleifer/distilbart-cnn-12-6`
